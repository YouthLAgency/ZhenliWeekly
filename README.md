## 真理周刊 / 真理月刊

**青联社（青年联络社）机关刊物**

**真理周刊与真理月刊是青联社（青年联络社）的机关刊物，分别以报纸和杂志的形态，承担理论传播、时事分析、思想教育、文艺创作的职能，是理论研究和思想统一的核心，也是“文化革命”战线的主要产出阵地。**

### 关于我们

青年联络社是以马克思主义为理论基础，以无产阶级中的工人与学生为主体的，以无产阶级和其他社会各阶层中的马克思主义先进分子组成的，以对青年群体以及广大人民群众进行共产主义社会主义思想教育、开展广泛的工人与学生社会实践运动为主要目标的集体。我们深层建构马列毛主义理论，致力于在文化革命、社会运动两个方向上积累力量，培养具有阶级意识、理论素养和实践能力的无产阶级知识分子青年骨干，为社会革命积累群众基础、理论基础与组织基础。

真理周刊与真理月刊由青联社内容组编辑，以马克思主义为理论基础，坚持无产阶级立场，以阶级分析作为认识社会和改造社会的基本方法。

### 我们的立场

一切内容坚持两条标尺：

**群众标尺** —— 一切理论、创作和行动，必须从人民群众的主体意识出发，让普通劳动者听得懂、有共鸣、得实惠。反对脱离群众的经院哲学和精英主义。

**实践标尺** —— 一切理论内容和观点都要接受长期的、科学的社会实践检验。说得再好不如做成一件事。
